How to connect Google Sheets (one-time setup)
  1. Open Google Sheets and create a new spreadsheet
  2. In row 1, add headers: Timestamp MRN Patient Name DOB Item Number Notes
  3. Click Extensions → Apps Script
  4. Delete any existing code, then paste the script below
  5. Click Deploy → New deployment
  6. Type: Web app · Execute as: Me · Who has access: Anyone
  7. Click Deploy and authorise when prompted
  8. Copy the web app URL and paste it into the field above

⚠️ Keep the Apps Script URL private — anyone with the URL can add rows to your sheet.
